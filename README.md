# neee-food

A responsive food-delivery storefront and TCS-504 System Design Assignment 2 demo.

The restaurant menu is vegetarian, and the food photography shows vegetarian dishes.

## Run locally

Open `index.html` in a browser. The site uses local JavaScript, CSS, and food photos in `assets/food/`.

## What's included

- Restaurant search, cuisine filters, menus, cart, checkout, and order-status demo.
- Food-delivery HLD diagram.
- Notification-system HLD and browser demo for preferences, channel statuses, history, and retries.
- URL-shortener HLD and browser demo for short links, redirects, and click counts.

## Demo limitations

Authentication, payments, notification delivery, and order tracking are simulated in the browser. Notification preferences/history and short-link mappings are stored in browser local storage. Production use requires backend services and provider integrations.

Food photography is from [Unsplash](https://unsplash.com/).
